# Basic Coding Interview Questions

Foundational questions commonly asked in coding interviews (including Google). Practice these before or alongside NeetCode 250.

Focus on clean logic, edge cases, and time/space complexity.

## Strings

1. Reverse a string
2. Check if a string is palindrome
3. Find matching (duplicate) characters in a string
4. Find non-matching (unique) characters in a string
5. Count vowels and consonants in a string
6. Check if two strings are anagrams
7. Count occurrence of a particular character in a string
8. Check if two strings are rotations of each other
9. Count numerical digits in a string
10. Find the first non-repeated character in a string
11. Remove special characters from a string
12. Swap two strings without using a third variable

## Arrays

13. Find the missing number in an array containing numbers from 1 to 100
14. Find matching (duplicate) elements in an integer array
15. Remove repeated elements from an integer array
16. Find the largest and smallest element in an unsorted array
17. Find the second largest element in an array
18. Reverse an array

## Sorting

19. Implement Bubble Sort
20. Implement Insertion Sort

## Linked List

21. Find the middle node of a linked list
22. Reverse a linked list
23. Remove duplicate elements from an unsorted linked list
24. Find the length of a linked list
25. Search for a specific value in a linked list
26. Get the third node of a linked list

## Numbers and Math

27. Check if a number is prime
28. Generate the first five Fibonacci numbers
29. Reverse a number
30. Find all factors of a number

## How to use this list

- Solve each question in Python, Java, and C++
- Write your own code (avoid copying common solutions)
- Discuss time and space complexity
- Handle edge cases (empty input, single element, negatives, etc.)
- After finishing these basics, continue with the NeetCode 250 daily problems

Official NeetCode 250 list: https://neetcode.io/practice
